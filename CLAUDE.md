# QU ACM Media Library

Photo and video library for the QU ACM student chapter: member-tier items are public (no sign-in), core-tier
items and uploads need a core-team session. Source requirements: `docs/HANDOFF.md` (backend)
and `docs/DESIGN-HANDOFF.md` (the Darkroom Archive design). The build plan with all system diagrams is
`plans/acm-media-library/plan.mdx` (open it with `plans/run-plan.sh`).

## Layout

- `packages/core` — shared code. `schemas/`, `enums`, `status`, `eta` (pure; the only parts `apps/web` may import), `db/` (Drizzle schema,
  pool, search), `crypto/` (ACMENC01 files, key wrapping), `eta.ts`, `status.ts`, `config.ts` (server env).
- `apps/api` — Fastify under Passenger. `apps/worker` — cron-driven job runner. `apps/web` — Vite + React 18.
- `py/mediaworker` — Python called by the worker via spawn; one JSON object on stdout.
- `migrations/` — generated by `npm run db:generate`; hand-written ones via `drizzle-kit generate --custom`.

## Commands

```sh
npm run db:up && npm run db:migrate && npm run bootstrap-admin   # local Postgres 9.6 on :55496
npm run dev         # API :3080 + Vite :5180 (proxies /api); OTP codes are printed in the API log
npm test            # vitest (creates and migrates acm_media_test on the docker database)
npm run typecheck
npm run test:py     # needs py/mediaworker/.venv
npm run seed        # demo users/events (dev only)
npm run once -w @acm/worker   # one worker pass over the queue
npm run build       # web + server bundles into dist/release
scripts/deploy.sh   # build, rsync, migrate, flip, restart (see docs/ops.md)
```

Copy `.env.example` to `.env.local` for development (`MAIL_TRANSPORT=log` prints OTP codes to the API log).

## Rules that are easy to break

- **Production is PostgreSQL 9.6.** No enums, identity/generated columns, `gen_random_uuid`, `websearch_to_tsquery`,
  `jsonb_path_*`, `INCLUDE` indexes or extensions. Statuses are text + CHECK; ids are UUID v7 from `@acm/core/ids`.
  Test SQL against the docker 9.6 image. Never `drizzle-kit push`.
- **Migrations are additive only**, so the previous release still runs if a deploy is rolled back.
- **404, never 403**, for anything a viewer may not see. Signed-out visitors read as `ANON` (member tier) via
  `readerOf()` in `apps/api/src/auth/plugin.ts`. All media access goes through `access()` in
  `apps/api/src/policy/canView.ts`.
- **Pages never call fetch.** `apps/web/src/api/` → `data/` hooks → `screens/` and `ui/`.
- **All UI strings go through i18next** (English only for now; layouts must stay RTL-safe).
- **Never log secrets:** OTP codes, cookies, emails on auth routes, key material, `MASTER_KEY`.
- `keys/`, `.env`, `.env.local` and `plans/*/.plan-url` are never committed.
